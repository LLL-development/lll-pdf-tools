# LLL PDF Tools

Developed by LLL Inc.'s dev team — visit us at https://www.live-laugh-love.world

A free, privacy-first PDF toolkit. Merge, split, and convert PDFs entirely in
your browser — nothing is uploaded to a server.

**Live:** https://lll-pdf-tools.pages.dev/

## Tools

**PDF**
- **Merge** — combine multiple PDFs into one
- **Split** — split a PDF into separate files
- **Rotate** — rotate pages
- **Compress** — reduce PDF file size
- **Lock / Unlock** — add or remove password protection
- **Delete Pages** — remove selected pages
- **Rearrange** — reorder pages
- **Extract** — pull out selected pages as a new PDF

**Office Conversion**
- **PDF to Word / Word to PDF**
- **Excel to PDF**
- **PowerPoint to PDF**

## Tech

- Plain HTML/CSS/JS, single-page app
- PDF handling via pdf.js and pdf-lib; document conversion via mammoth (Word), xlsx (Excel), html2canvas + jsPDF (rendering to PDF); archiving via JSZip
- Multi-language interface, light/dark theme
